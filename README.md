# Ayush Guha

**UC Berkeley | Physics + Data Science | Scientific Computing · ML · Experimental Physics**

I'm a UC Berkeley undergraduate studying Physics and Data Science. I build computational tools and analyze scientific data, with interests in materials characterization, experimental automation, machine learning for science, and hardware–software systems.

## Research

- **Stanford SLAC / SSRL:** Research intern working on ferroelectric and oxide semiconducting materials using synchrotron X-ray diffraction (XRD). My work centers on an automated feedback system for XRD experiments (built with bluesky and ophyd) and live data visualization. [Stanford Synchrotron Radiation Lightsource](https://www-ssrl.slac.stanford.edu/)
- **UC Berkeley CDSS Data Discovery Program:** Data science research on scientific data, including electrochemical impedance spectroscopy (EIS) analysis for advanced nuclear reactor materials and a project on neural search for crystal identification using contrastive learning and optimal transport (in progress). [Data Discovery Program](https://datadisco.cdss.berkeley.edu/)
- **Earlier research:** Thermosyphon-based passive cooling and thermal-performance experiments (San Jose State University, Intelliscience Research Institute), Kronig–Penney band-gap modeling (UCSC COSMOS), and eclipsing-binary light-curve analysis (UCSB).
