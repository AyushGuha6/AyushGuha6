# Ayush Guha

**UC Berkeley | Physics + Data Science | Scientific Computing · ML · Experimental Physics**

I'm a UC Berkeley undergraduate studying Physics and Data Science. I build computational tools and analyze scientific data, with interests in materials characterization, experimental automation, machine learning for science, and hardware–software systems.

## Research

- **SLAC National Accelerator Laboratory (DOE SULI):** Research intern through the DOE [Science Undergraduate Laboratory Internships](https://science.osti.gov/wdts/suli) program, working on ferroelectric and oxide semiconducting materials with synchrotron X-ray diffraction (XRD) at the [Stanford Synchrotron Radiation Lightsource](https://www-ssrl.slac.stanford.edu/). I developed an automated feedback system for XRD experiments (using bluesky and ophyd) and a live data visualization interface.
- **UC Berkeley Data Discovery Program (in collaboration with [NIST](https://www.nist.gov/)):** Team member on *Neural Search for Scientific Data: Contrastive Learning and Optimal Transport for Crystal Identification*, building and benchmarking a retrieval system for powder X-ray diffraction patterns. The work compares classical baselines (peak matching, optimal transport) with neural contrastive models and focuses on rigorous evaluation. Research in progress. I've also worked on electrochemical impedance spectroscopy (EIS) analysis for advanced nuclear reactor materials through the same program. [Data Discovery Program](https://datadisco.cdss.berkeley.edu/)
- **UC Berkeley CDSS Data Discovery Program:** Data science research on scientific data, including electrochemical impedance spectroscopy (EIS) analysis for advanced nuclear reactor materials and a project on neural search for crystal identification using contrastive learning and optimal transport (in progress). [Data Discovery Program](https://datadisco.cdss.berkeley.edu/)
- **Earlier research:** Thermosyphon-based passive cooling and thermal-performance experiments (San Jose State University, Intelliscience Research Institute), Kronig–Penney band-gap modeling (UCSC COSMOS), and eclipsing-binary light-curve analysis (UCSB).
